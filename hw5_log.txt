- GET /api/runs and /api/runs/{session_id}: run status and summary.
- GET /api/events?since=&limit=&ticket_id=&session_id=: what each agent said,
  which tools it used, and the results, from audit_trail.json. Poll with
  next_since.
- GET /api/payments: prepared, approved, denied, failed and void payments.
- POST /api/payments/{id}/request-code: sends the one-time 2FA code
  (simulated as output/2fa/one_time_code.txt).
- POST /api/payments/{id}/approve {approved_by, code}: the ONLY route that
  changes cash. It calls the pay tool through MCP with a signed approval, then
  updates the ticket (rent paid -> resolved, invoice paid -> waiting_on_vendor).
- POST /api/payments/{id}/deny {denied_by, reason}.
- GET /api/cash: balances from cash_accounts, obligations, and the
  pending-approval total.
- POST /api/reset: copies the original DB over the working copy, voids pending
  payments, and keeps the audit trail.
